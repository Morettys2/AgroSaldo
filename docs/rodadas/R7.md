# AgroSaldo — R7: componentes visuais e acessibilidade 🎨

Rodada de **acabamento de interface**. Em vez de cada tela desenhar o próprio botão, a própria mensagem de "vazio" e o próprio espaçamento, agora existe **um jeito só**, guardado em `core/ui` e `ui/theme`.

O visual fica praticamente igual. O que melhora:

- tudo alinhado igual entre as telas;
- botões que não cortam o texto quando o celular está com a fonte grande (comum em quem tem vista cansada, caso de muito produtor);
- o erro de leitura que a R6 preparou agora aparece na tela.

---

## 1. Como pegar esta rodada

Branch `rodada/r7-componentes`, com PR aberto **em cima da R6** (o PR da R7 aponta para a branch da R6).

1. Faça primeiro o merge da **R6** na `main`.
2. Depois, no PR da R7, o GitHub oferece trocar a base para `main`; é só aceitar.
3. No Android Studio: `git checkout rodada/r7-componentes`, **Sync** e **Rebuild**.
4. Abra os `@Preview` de `core/ui/Botoes.kt` e `core/ui/Estados.kt`: cada um tem a versão normal e uma com **fonte 2x**.

✔️ CI verde: compila, **438 testes** passando, nenhum aviso do Kotlin.

## 2. O que mudou (e por quê)

### 1. Botões compartilhados — `core/ui/Botoes.kt`

| Componente | Quando usar | Exemplo |
|---|---|---|
| `BotaoPrincipal` | a ação da tela | Entrar, Salvar ajustes, Salvar propriedade |
| `BotaoDestaque` | a ação que o olho tem que achar primeiro (verde-limão) | Salvar despesa, Cadastrar propriedade |
| `BotaoTonal` | ação de apoio dentro de um cartão | Permitir notificações |
| `BotaoSecundario` | ação com contorno; `perigo = true` pinta de vermelho-despesa | Sair da conta, Excluir propriedade |

Eram **14 botões feitos à mão**, com `.height(56.dp)` fixo e alturas 48/52/56/60 misturadas.

O problema do `.height(56.dp)`: com a fonte do sistema em 150–200%, o texto "Aceito e quero continuar" quebra em duas linhas, mas o botão continua com 56 dp, e **metade do texto some**. Agora é `heightIn(min = 56.dp)`: no mínimo 56, crescendo se precisar.

Também tem `carregando = true`, que troca o texto pela rodinha e desliga o botão. Login, cadastro e troca de senha usavam isso, cada um com 10 linhas repetidas.

👉 **Lição:** em Compose, prefira `heightIn(min = …)` a `height(…)` em qualquer coisa com texto. Tamanho fixo só para o que não é texto (ícone, avatar).

### 2. Estados de tela — `core/ui/Estados.kt`

- `Carregando()`: a rodinha centralizada, com "Carregando" para o leitor de tela.
- `EstadoVazio(texto, titulo?, icone?, acao?)`: "nada aqui ainda, faça isso". Substitui o `Aviso` que estava **copiado** em Sítios e Lançamentos e o `EstadoVazio` que só o Clima tinha.
- `FaixaDeAviso` / `EstadoErro`: a faixa no topo ("Sem internet…", "Não foi possível carregar…"). É uma *liveRegion*: o TalkBack lê sozinho quando ela aparece.

O `erro` que a R6 colocou nos UiState agora aparece no **Início, Lançamentos, Histórico e Clima**.

Um detalhe no Início: se a **primeira** leitura falhasse, a tela mostrava "Comece cadastrando um sítio" para quem já tinha sítio. Agora ela mostra o erro.

### 3. Escala de espaços — `ui/theme/Espacos.kt`

```kotlin
Espacos.minimo   //  4 dp
Espacos.pequeno  //  8 dp
Espacos.medio    // 12 dp
Espacos.padrao   // 16 dp
Espacos.largo    // 20 dp  ← Espacos.margemDaTela
Espacos.grande   // 24 dp
Espacos.enorme   // 32 dp
```

**149 linhas** trocaram `20.dp` solto por um nome. O valor é o mesmo; o que muda é que agora dá para ler a intenção (`margemDaTela`) e mudar num lugar só.

A única diferença visível: o **Histórico** usava margem 16 nos cartões e 20 nas linhas. Agora é 20 em tudo, como nas outras abas.

👉 **Lição:** é o mesmo princípio das cores em `Color.kt`: número mágico espalhado vira **token** com nome. Igual a variável de CSS (`--espaco-m`) ou o `spacing` do Tailwind.

### 4. Um seletor de propriedade só

Havia o `SeletorPropriedadeCabecalho` (Início, Lançamentos, Clima) e o `SeletorPropriedade` (Histórico), com tamanho de toque e textos diferentes.

Agora é um só, `SeletorPropriedade(..., noCabecalho = true/false)`, que troca apenas as cores. O Histórico ganha o rótulo "Propriedade" e a mesma área de toque de 48 dp.

### 5. Acessibilidade

- **Barra de baixo:** o nome da aba encolhia até **9 sp** para caber. Agora o mínimo é **11 sp**, o menor tamanho legível recomendado.
- **Linhas clicáveis** (itens da Conta, meses do Histórico): ganharam `role = Role.Button`. O TalkBack diz "Abril, botão, toque duas vezes para ver os lançamentos do mês" em vez de só "Abril".
- **Teclado numérico** do lançamento: as teclas usam `heightIn` e crescem com a fonte.
- **Previews com fonte 2x** em todas as telas principais. No Android Studio dá para ver na hora se algo corta.

### 6. Textos repetidos — `core/util/TextosComuns.kt`

O formulário dizia "Selecione" num lugar e "Escolha" em outro para a mesma coisa. Agora os dois usam "Escolha a propriedade", e "Nenhuma propriedade" vem de uma constante só.

### Já resolvido na auditoria (estava no plano da R7)

- Permissão de notificação negada duas vezes abre os ajustes (M9).
- O rascunho do formulário sobrevive se o Android matar o app (M12).
- O Início não pisca antes do novo aceite da política (M3).

## 3. O que testar no celular

- [ ] **Fonte grande:** Configurações → Tela → Tamanho da fonte no máximo. Abra o login, o cadastro, o formulário de lançamento e a Conta. Nenhum botão pode cortar o texto.
- [ ] **TalkBack** (opcional): ligue e passe pelas abas. Elas são lidas como "Aba", e os meses do Histórico como "botão".
- [ ] **Estados vazios:** numa conta nova, confira Início, Lançamentos, Sítios, Clima e Histórico. Todas mostram um cartão explicando o que fazer.
- [ ] **Sem internet** no Clima: aparece a faixa "Sem internet…".
- [ ] **Histórico:** as margens dos cartões batem com as das linhas dos meses.
